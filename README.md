# HydroPro Mesher Validation

This repository presents CFD validation cases generated using HydroPro's automated 3D meshing technology.

The objective is to document mesh quality, CFD accuracy, and reproducibility on representative external-flow and marine-hydrodynamics problems.

## Validation cases

### Duisburg Test Case (DTC)

Free-surface ship-resistance simulation using OpenFOAM.

The case includes the generated mesh, CFD setup, force history, and comparison against experimental resistance data.

[View DTC validation](cases/dtc/)

### Ahmed Body — 25° Slant

Steady RANS simulation of the 25° Ahmed body at 40 m/s using OpenFOAM.

The case includes the generated mesh, CFD setup, aerodynamic coefficients, and comparison against published reference data.

[View Ahmed 25° validation](cases/ahmed25/)
