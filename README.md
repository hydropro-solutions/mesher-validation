# HydroPro Mesher Validation

This repository contains public CFD validation cases using meshes generated by HydroPro's proprietary automated 3D meshing technology.

The purpose of the repository is to make the **generated meshes, CFD setup, and validation results inspectable and reproducible**. The mesher itself and its generation configuration are not distributed.

## Cases

- **Duisburg Test Case (DTC)** — free-surface ship resistance validation with OpenFOAM `interFoam`.
- **Ahmed Body 25°** — steady external-aerodynamics validation with OpenFOAM `simpleFoam`.

## What is public

For each case, the public package is intended to contain the final OpenFOAM mesh, CFD dictionaries required for the solver, relevant solution fields/results, and validation data.

## What is not public

HydroPro mesher configuration files, internal meshing-stage artifacts, proprietary generation parameters, and local development metadata are intentionally excluded.

The public material validates the **output mesh and CFD result**; it is not a distribution of the meshing pipeline.

## Status

These cases are part of the validation record for the current frozen mesher MVP.
