# Duisburg Test Case (DTC) — Free-Surface Resistance Validation

This case documents a free-surface resistance calculation on the Duisburg Test Case (DTC) hull using a mesh generated by HydroPro's proprietary automated 3D meshing technology.

Mesher configuration files are intentionally not distributed. The release is intended to allow inspection of the generated mesh and independent review/re-execution of the CFD setup.

## Case summary

| Item | Value |
|---|---|
| Geometry | Duisburg Test Case (DTC) |
| Domain | Half-domain with symmetry plane |
| Inflow speed | 1.668 m/s |
| CFD solver | OpenFOAM `interFoam` |
| OpenFOAM version | 5.x |
| Turbulence model | RANS, k-ω SST |
| Mesh cells | 278,418 |
| Mesh faces | 868,415 |
| Internal faces | 838,323 |
| Hull boundary faces | 10,819 |
| Final simulated time/step | 8000 |

## CFD result

The OpenFOAM force function object reports pressure and viscous contributions separately on the hull.

Using the final 2,000 recorded force samples:

| Quantity | Mean |
|---|---:|
| Pressure resistance | 3.690 N |
| Viscous resistance | 12.419 N |
| Total resistance | 16.108 N |

The experimental total-resistance value used for comparison is **15.915 N for the half hull**. This gives a total-resistance difference of approximately **+1.21%**.

The experiment provides total resistance; the pressure/viscous split above is the numerical OpenFOAM force decomposition and should not be interpreted as an independently measured experimental split.

### Interpretation note

The experimental DTC condition used for comparison allowed the model to respond in sinkage and trim, whereas this numerical case is a fixed-hull calculation at the nominal position. The comparison should be interpreted with that distinction in mind.

## Included material

The public case is intended to include:

- the generated `constant/polyMesh`,
- OpenFOAM solver dictionaries required for the CFD run,
- initial/final solution fields,
- the recorded force history,
- the geometry only where redistribution is permitted.

HydroPro mesher setup/configuration files are deliberately excluded.

## Inspecting the mesh

From the CFD case directory:

```bash
checkMesh
```

For visualization, create/open a `.foam` marker file and inspect the mesh and solution in ParaView.

## CFD setup source

The underlying DTC CFD setup is based on the DTC case distributed with the OpenFOAM tutorials. Users who want a clean initial field set or the original tutorial workflow can obtain it directly from the corresponding OpenFOAM tutorial installation.

This public HydroPro package focuses on the **generated mesh and the resulting CFD validation**.

## Reproducibility scope

This case is published to validate the **generated mesh and resulting CFD performance**. It does not provide the proprietary HydroPro meshing parameters needed to regenerate the mesh from geometry.
